# Video Game Sales Analysis

Exploratory data analysis of global video game sales to identify performance patterns across platforms, genres, reviews, and regions using Python and Jupyter Notebook.

## Project Objective
Analyze historical video game sales to identify factors associated with commercial success across major regional markets.

## Dataset
- `games (2).csv`

Main fields analyzed include platform, genre, year of release, regional sales (NA/EU/JP/Other), critic score, user score, and rating.

## Analysis Scope
- Data cleaning and preprocessing (missing values, type normalization, score formatting)
- Platform and lifecycle analysis by release year and total sales
- Genre performance analysis across time and markets
- Review-score vs. sales relationship analysis
- Regional market comparison (North America, Europe, Japan)

## Business Questions Answered
- Which platforms and genres are most associated with higher sales?
- How do user and critic reviews relate to game performance?
- How do market preferences differ across regions?

## Key Findings
- Sales performance is concentrated in a subset of platforms and genres.
- Regional market behavior differs, reinforcing the need for localized release and marketing strategies.
- Review variables provide directional context but should be interpreted together with platform, genre, and market effects.
